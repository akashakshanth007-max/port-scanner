# Port Scanner

A web-based Port Scanner project designed for educational and authorized security testing.

## Features

- Port scanning using Nmap
- Service and version detection
- Risk classification
- Security recommendations
- User Login and Registration
- Scan history using Supabase
- HTML report generation
- Docker support
- Wireshark packet capture validation

## Technologies Used

### Frontend
- React
- Vite
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask
- Nmap

### Other Tools
- Docker
- Wireshark
